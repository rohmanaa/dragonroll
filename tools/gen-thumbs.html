Generator thumbnail Dragon Roll

Merender SEKALI dari renderer asli (karakter memakai set LENGKAP semua bagian, dadu, power, aura, dan pet 3D), lalu menyimpannya sebagai foto statis supaya Shop/Dadu tidak perlu render lagi.

Buka lewat server lokal/deploy dari akar repo (mis. /tools/gen-thumbs.html) memakai Chrome (perlu encoder WebP). Hasil: ZIP berisi struktur folder repo, ekstrak ke akar repo.
